# CS 209: what's been taught (the scope for new problems)

Source: `/data/Everything/CS 209 Notes.md`. Update this file from each new lecture's notes. Problems may combine
anything under **Taught**, across lectures, but nothing under **Not taught yet**.

## Taught
- **9-24: How Java runs.** JDK / JRE / JVM; compiled (2 stages) vs interpreted (1 stage); source → bytecode → JVM;
  compile-time errors (syntax, type mismatch) vs runtime errors (missing file, no permission).
  Project layout (src → class → main); `public class X` + `public static void main(String[] args)`; what public, void,
  main and the parameters mean; `{ }` scope.
- **9-24: Printing.** `System.out.print` vs `println`; Strings in `" "`, chars in `' '`; printing expressions;
  `+` concatenation, left to right; escape sequences `\"`, `\\`, `\n`, `\t`; `//` comments.
- **9-29: Concatenation vs addition.** Pure addition vs pure concatenation; parentheses first; `*` before `+`;
  `"Result: " + 10 - 5` is a compile error.
- **9-29: Variables.** A variable is typed storage; declare / initialize / both; errors: undeclared, uninitialized, mismatch
  (`int price = 2.5;`). Types: `int` (4 B), `double` (8 B), `boolean` (default false), `char` (2 B), `String` (object).
- **9-29: Arithmetic.** `%` modulus; int / int → int (truncates); double with int → double; `double x = 5 / 2` stores 2.0.
- **10-1: char as a number.** chars have numeric codes ('A' = 65); `int x = 'A' + 10` → 75.
  Naming: can't start with a digit, lowercase start by convention. IPO (input, process, output), e.g. seconds → min/sec.
- **10-6: for loops.** Why loops (repeat a step); two kinds: known number of iterations → `for`, unknown → `while` /
  `do-while` (named only, syntax not taught). `for (int i = start; test; update) { ... }`: init runs once, then
  test → body → update → test… while the test is true. Tests with `<`, `>`, `<=`, `>=`. Updates `i = i + n`, `i++`,
  `i--`, `i += n`, `i -= n`, `x += var`. Accumulating (`sum = sum + i`, starting from 0). Print the result after the
  loop closes. Without `{ }` only the first statement after the `for` repeats. The counter `i` only exists inside the loop.
  Notes corrections: the operators are `>=` / `<=` (not `=>` / `=<`, which don't compile), `i += 2` has no space
  inside `+=`, and `print(i); println("*")` prints `1*` (no space).

## Not taught yet (don't require these)
Casting syntax `(int)`, `(char)`; `while` / `do-while` syntax (only named); nested loops; `if` / `else`; `==`, `!=`,
`&&`, `||`; `break` / `continue`; `Scanner` / input; `Math` methods; String methods (`.length()`, `.charAt()`);
methods other than `main`; arrays; objects / classes beyond `main`.

Reassigning a variable (`x = x * 2;`) is fair game: it follows from "a variable is storage". From 10-6 on, so are
`++`, `--`, `+=`, `-=` and the four comparison operators, inside or outside loops.
