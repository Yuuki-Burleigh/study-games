# CS 209: what's been taught (the scope for new problems)

Source: `/data/Everything/School/CS 209/CS 209 Notes.md`. Update this file from each new lecture's notes. Problems may combine
anything under **Taught**, across lectures, but nothing under **Not taught yet**.

## Taught
- **9-24: How Java runs.** JDK / JRE / JVM; compiled (2 stages) vs interpreted (1 stage); source → bytecode → JVM;
  compile-time errors (syntax, type mismatch) vs runtime errors (missing file, no permission).
  Project layout (src → class → main); `public class X` + `public static void main(String[] args)`; what public, void,
  main and the parameters mean; `{ }` scope.
- **9-24: Printing.** `System.out.print` vs `println`; Strings in `" "`, chars in `' '`; printing expressions;
  `+` concatenation, left to right; escape sequences `\"`, `\\`, `\n`, `\t`; `//` comments.
- **9-29: Concatenation vs addition.** Pure addition vs pure concatenation; parentheses first; `*` before `+`;
  `"Result: " + 10 - 5` is a compile error.
- **9-29: Variables.** A variable is typed storage; declare / initialize / both; errors: undeclared, uninitialized, mismatch
  (`int price = 2.5;`). Types: `int` (4 B), `double` (8 B), `boolean` (default false), `char` (2 B), `String` (object).
- **9-29: Arithmetic.** `%` modulus; int / int → int (truncates); double with int → double; `double x = 5 / 2` stores 2.0.
- **10-1: char as a number.** chars have numeric codes ('A' = 65); `int x = 'A' + 10` → 75.
  Naming: can't start with a digit, lowercase start by convention. IPO (input, process, output), e.g. seconds → min/sec.
- **10-6: for loops.** Why loops (repeat a step); two kinds: known number of iterations → `for`, unknown → `while` /
  `do-while` (named only, syntax not taught). `for (int i = start; test; update) { ... }`: init runs once, then
  test → body → update → test… while the test is true. Tests with `<`, `>`, `<=`, `>=`. Updates `i = i + n`, `i++`,
  `i--`, `i += n`, `i -= n`, `x += var`. Accumulating (`sum = sum + i`, starting from 0). Print the result after the
  loop closes. Without `{ }` only the first statement after the `for` repeats. The counter `i` only exists inside the loop.
  Notes corrections: the operators are `>=` / `<=` (not `=>` / `=<`, which don't compile), `i += 2` has no space
  inside `+=`, and `print(i); println("*")` prints `1*` (no space).
- **10-8: Loop scope & nested loops.** The counter can't be re-declared inside its own loop (`int i = 3;` in the
  body won't compile), and after the loop it's gone: `i = 5;` there won't compile, but a fresh `int i = 5;` (or a new
  `for (int i ...)`) is fine. Nested loops: an outer loop whose body holds an inner loop, which runs in full on every
  outer pass; the two need different counter names. Independent nesting: the inner body runs m × n times.
  Dependent (triangle / staircase) nesting: the inner bound uses the outer counter (`x <= i`). `println()` after the
  inner loop ends each row. Quiz feedback recap: int with double gives a double that keeps its fraction (7 / 2.0 = 3.5).
  Notes correction: the 10-8 example (`i < 3`, `x < 3`, `print(i)`) prints `11` then `22` (2 rows of 2, the digits of i),
  not three rows of `iii`.
- **10-13: Pre-increment.** `++x` adds 1 to x first, then the new value is used (`int y = ++x * 2;`). `x + 1` only
  reads x and doesn't change it.
- **10-15 / 10-20: Static methods.** Why methods (clear structure, reuse, easy to refine / debug). Header
  `public static returnType name(type param, ...) { }`; every parameter needs a type. Three kinds: (1) closed box,
  `void`, nothing in or out; (2) `void` with inputs; (3) returns a value (with or without inputs; one value out,
  several in). `void` returns nothing; otherwise `return value;` with a value of the declared type. main steers the
  program: a method runs only when called (`name(args);`), once per call, in the order main calls them. Arguments are
  copies of the VALUE and match parameters by position (names can differ; wrong count or type is a mismatch error).
  A returned value is lost unless caught: `count = incrementValue(count);`. Global variable:
  `public static int count = 0;` in the class, outside every method, usable by all methods; a local variable or
  parameter with the same name takes precedence inside its method (passing a global as an argument makes a local
  copy). Variables declared in main (or in another method) aren't visible elsewhere. Examples: temperature converter
  split into `tempConverter` (returns a double) and `printer` (void); methods containing `for` loops.
  Notes corrections: it is lowercase `public static void` / `double` (not `Public Static Void` / `Double`); the type 2
  example needs a type in the header (`void printHello(int courseNumber)`); `double average = (exam1 + exam2)/2;`
  with int parameters divides as ints first, so 85 and 90 give 87.0, not 87.5.

## Not taught yet (don't require these)
Casting syntax `(int)`, `(char)`; `while` / `do-while` syntax (only named); `if` / `else`; `==`, `!=`,
`&&`, `||`; `break` / `continue`; `Scanner` / input; `Math` methods; String methods (`.length()`, `.charAt()`);
method overloading; methods calling other methods; `return` in the middle of a method; recursion; arrays; objects / classes beyond `main`.

Reassigning a variable (`x = x * 2;`) is fair game: it follows from "a variable is storage". From 10-6 on, so are
`++`, `--`, `+=`, `-=` and the four comparison operators, inside or outside loops.
